# Pony Club

Уютный сборник четырёх браузерных игр по мотивам **My Little Pony: Friendship Is Magic**. Интерфейс на русском, избранное, личные рекорды и восемь достижений. Первые три игры доступны на компьютерах и телефонах; **«Магия единорога» — только на ПК с мышью**.

## Поиграть локально

Откройте **index.html** в современном браузере. Сборка, установка зависимостей и аккаунт не нужны. Изображения, шрифты и код находятся в проекте; интернет для локальной игры не требуется.

Для запуска через локальный сервер, если установлен Python:

```powershell
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Четыре игры

| Игра | Геймплей | Управление |
| --- | --- | --- |
| Радужный полёт | Собирайте звёзды и обходите тучи в течение 75 секунд. Три сердечка; каждая звезда даёт 10 очков. | Стрелки / WASD, либо перетаскивание по игровому полю. |
| Парочки дружбы | Открывайте карточки и найдите шесть пар пони. Ограничения времени нет; меньше ходов и времени — выше результат. | Мышь, касание или Tab и Enter. |
| Мелодия дружбы | 48 нот и 30 секунд оригинальной мелодии. Совмещайте падающие ноты с линией и увеличивайте серию. | Физические клавиши D, F, J, K при любой раскладке или четыре экранные кнопки. |
| Магия единорога | Защитите поляну от монстриков за 60 секунд. Водите курсором по рогу, чтобы он рос и накапливал магию. Чем выше заряд, тем больше урон, размер и скорость снаряда. Три сердечка. | **Только ПК:** удерживайте ЛКМ и водите по рогу; отпустите ЛКМ и кликните по цели для выстрела. |

В «Магии единорога» неподвижное удержание ЛКМ и движения вне рога не увеличивают заряд. Выстрел доступен от 15% заряда; максимальный заряд даёт 5 единиц урона. Без заряда рог маленький и загнут вниз; при зарядке он плавно выпрямляется и увеличивается. После выстрела заряд расходуется, а изображение плавно возвращается в исходную форму. Накопленная магия сохраняется при отпускании кнопки и паузе. На устройствах с сенсорным управлением без мыши игра помечена «Только на ПК» и исключена из случайного выбора.

Внешний вид рога задаёт пользовательская картинка `assets/horn.png`. Изгиб — отдельная анимация изображения в `visualGeometry()`; область зарядки по просьбе автора осталась прежней и рассчитывается функциями `geometry()` и `onHorn()`. Снаряды и искры выходят из видимого кончика. Настроенная ширина `half = 34 + g.charge * 10` сохранена.

Звук по умолчанию выключен. Его можно включить кнопкой динамика. Мелодия и эффекты синтезируются через Web Audio API. Ритм-игра доступна без звука.

Кнопка паузы или Esc приостанавливает игру. Пробел также работает в играх с игровым полем. При смене вкладки или окна включается автоматическая пауза. Чтобы закрыть активную игру, нажмите крестик или «К другим играм» на экране паузы.

Прогресс хранится в `localStorage` этого браузера. На другом устройстве или другом адресе сайта будет отдельный прогресс. Если браузер запрещает сохранение, игры продолжают работать в текущем сеансе.

## Публикация на GitHub Pages

Репозиторий пока не создавался: сначала просматриваем игры.

1. Создайте репозиторий GitHub и загрузите **всё содержимое этой папки**, включая `.github/workflows/pages.yml`. Основная ветка должна называться `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Запустите workflow **Publish Pony Club** из вкладки Actions либо отправьте новый коммит в `main`.
4. После успешной публикации адрес сайта появится в Settings → Pages и в результате deployment.

Workflow уже включён. Он публикует только файлы сайта и папку `assets`, без документации и служебных материалов. Все пути относительные, поэтому сборник работает и по адресу вида `https://имя.github.io/pony-club/`.

Источники настройки: [официальная инструкция по GitHub Pages workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Устройство проекта

```text
index.html                 Главная страница и диалоги
styles.css                 Адаптивное оформление и локальные шрифты
art.js                     SVG-иллюстрации пони, карточек и иконок
app.js                     Игры, звук, рекорды и достижения
horn.js                    Зарядка рога, снаряды и монстрики
horn.css                   Оформление четвёртой игры и сетки сборника
tests/horn.test.cjs         Проверки зарядки, силы и попаданий
assets/                    Иллюстрация, favicon и шрифты
.github/workflows/pages.yml Публикация на GitHub Pages
ARTWORK.md                 Происхождение иллюстрации и промпт
QA.md                      Проверки перед передачей
```

Сайт работает без сторонних библиотек, рекламы, аналитики, загрузки аудиофайлов и серверного кода. Современные версии Chrome, Edge, Firefox и Safari поддерживают используемые браузерные API.

Для разработчиков: проверки новой игры запускаются командой `node --test tests/horn.test.cjs`. Установка npm-пакетов не требуется; Node.js нужен только для тестов, не для запуска сайта.

## Фан-проект и материалы

Неофициальный фан-проект. My Little Pony и персонажи принадлежат Hasbro. Проект не связан с Hasbro и не одобрен правообладателем. Иллюстрация создана с помощью ИИ; SVG-графика и синтезируемая мелодия подготовлены для этого проекта.

Шрифты Manrope и Nunito распространяются по SIL Open Font License. Тексты лицензий находятся в `assets/fonts/`. Сведения об иллюстрации — в `ARTWORK.md`.
