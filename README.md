# Pony Club

Уютный сборник четырёх браузерных игр по мотивам **My Little Pony: Friendship Is Magic**. Интерфейс на русском, избранное, личные рекорды и восемь достижений. Первые три игры доступны на компьютерах и телефонах; **«Магия единорога» — только на ПК с мышью**.

## Фан-проект и материалы

Неофициальный фан-проект. My Little Pony и персонажи принадлежат Hasbro. Проект не связан с Hasbro и не одобрен правообладателем. Иллюстрация создана с помощью ИИ; SVG-графика и синтезируемая мелодия подготовлены для этого проекта.
